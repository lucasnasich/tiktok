## Figma

- Para crear y ensamblar creativos (slides, carruseles, overlays).
- Plugin oficial de Cursor, ya disponible en el editor.
- El agente debe usar Figma MCP antes de pedirte trabajo manual.

## Buffer

- Para programar y publicar en redes.
- Configurado en `.cursor/mcp.json` (sin tokens en el repo).
- Primera vez: Cursor → Settings → Tools & MCP → buffer → **Connect** (OAuth).

## Regla general

Si existe una herramienta MCP para la tarea, el agente la usa primero.
